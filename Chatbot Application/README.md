# Chatbot Application - Chatterbot

**Video Tutorial:** https://youtu.be/UUbF4zvS6qA

## Project Information

The objective of the project is to build a chatbot application using Python and ChatterBot. The chatbot supports both retrieval-based and corpus-based conversation. You can initialize a general-purpose bot with pre-trained conversational corpora or train custom dialog patterns for specialized domain tasks.

## Prerequisites & Compatibility

> [!WARNING]
> `chatterbot` and `chatterbot-corpus` rely on legacy language processing modules (`spacy` 2.x and older `nltk` versions) and are compatible with **Python 3.7 and 3.8**.
> If you are using Python 3.10+, run this project inside a dedicated Python 3.8 virtual environment.

### Installation

Inside a Python 3.7/3.8 environment:
```bash
pip install chatterbot==1.0.5 chatterbot-corpus==1.2.0
```

## Running the Notebook

Launch Jupyter Notebook:
```bash
jupyter notebook "Chatbot Application - Chatterbot.ipynb"
```
